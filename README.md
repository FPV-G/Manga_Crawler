# Manga_Crawler（漫画爬虫）

多源漫画批量下载器：读取名单，聚合搜索多个漫画资源站，自动选择最优资源并下载整本漫画，支持断点续传、跨源续传、缺页补齐、章节缓存、封面下载和交互控制菜单。

## 功能

- 聚合搜索：同时检索拷贝漫画、再漫画、包子漫画、如漫画等多个资源站
- 自动选源：按配置的源优先级 + 可读章节数 + 章节总数 + 名称匹配度综合选择
- 章节差距纠错：第一优先源与章节最多的源相差过大时，自动判定匹配到同人/错误作品，改选章节最多的源
- 多章节 / 多线程下载，图片按 001、002... 顺序命名
- 断点续传：重新运行自动跳过已下载章节
- 跨源续传：某源下载失败自动切换下一源，从失败章节继续
- 缺页补齐：每次运行按源返回的页数校验，缺页自动补、完整跳过
- 章节缓存：图片列表缓存到本地，换源后无需重复联网查询
- 封面下载：自动保存封面到作品主目录
- 获取失败自动重试：搜索无结果或章节图片列表获取失败时持续重试（默认 65 秒，`fetch_retry_seconds` 可配），进度区显示实时倒计时，超时仍失败才跳过
- 单行本/卷识别：章节页数超过上限（默认 150 页）或章节名含“第x卷”时自动跳过，只下载话
- 失败记录完整：换源过程中的失败章节也会写入 `失败.log`（即使最终换源成功）
- 防卡死：章节进度卡住超过设定时间自动换源；图片下载超时可配置
- 交互菜单：Ctrl+F 打开菜单，支持跳过漫画/章节、重下上一章、暂停等

## 支持资源

| 资源 | 说明 |
| --- | --- |
| 拷贝漫画 | 默认 API 线路，需网络可达 |
| 再漫画 | 部分章节需登录/会员，账号可在 config 配置 |
| 包子漫画 | 部分网络环境会屏蔽非本地节点 |
| 如漫画 | 长标题自动截短搜索 |
## 安装

要求 Python 3.10+。

```bash
pip install requests zhconv beautifulsoup4 pycryptodome curl_cffi
```

## 快速开始
到[Release](https://github.com/FPV-G/Manga_Crawler/releases)下载最新版本并解压出来
1. 编辑 `名单.txt`，每行一个漫画名。
示例
```
葬送的芙莉莲
药屋少女的独语
我推的孩子
胆大党
坂本日常
```
2. 编辑 `config.json` 并按需修改（脚本默认读取当前目录的 `config.json`）。
3. 运行：

```bash
python kaobei_downloader.py
```

## 配置

所有关键参数集中在 `config.json`（每项带注释）：

| 配置项 | 说明 |
| --- | --- |
| `sources` | 启用资源，逗号分隔 |
| `source_priority` | 源优先级，靠前优先 |
| `chapter_gap_threshold` | 源间章节数差距达到该值自动选章节最多的源 |
| `chapter_workers` | 同时下载章节数 |
| `image_workers` | 每章图片并发数 |
| `image_rate` | 图片每分钟请求上限，0 不限 |
| `timeout` | 单张图片下载超时秒数 |
| `stall_timeout` | 章节卡住多少秒后换源 |
| `fetch_retry_seconds` | 获取失败后的重试总时长（秒）：搜索无结果 / 章节图片列表获取失败时持续重试，超时仍失败才跳过该章 |
| `max_pages_per_chapter` | 单话页数上限，超过判定为单行本/合集（卷）直接跳过（0 关闭） |
| `skip_volume_titles` | 章节名含“第x卷”字样直接跳过（单行本/合集） |
| `cache_ttl_hours` | 章节缓存有效期（小时） |
| `match_threshold` | 名称近似匹配阈值 |
| `zmh_account` / `zmh_password` | 再漫画登录账号（可选） |

命令行参数优先级高于配置文件，例如：

```bash
python kaobei_downloader.py --range 1-50
python kaobei_downloader.py --refresh
python kaobei_downloader.py --source-priority rumanhua,copy,zmh
```

## 交互控制

| 按键 | 功能 |
| --- | --- |
| `Ctrl+C` | 第一次提示，第二次退出 |
| `Ctrl+F` | 打开控制菜单 |

菜单支持：跳过当前漫画、跳过当前章节、重新下载上一章节、暂停/继续、显示状态、退出程序。
